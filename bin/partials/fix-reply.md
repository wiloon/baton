Start the reply with a `## Must fix` section that answers the review's Must fix items in their numbering, one line each: `N. adopted — what you changed` or `N. rejected — why` (write `none` when the feedback has no numbered Must fix list); the runner counts these lines. Follow it with a `## Nits` section (write `none` when the feedback has no nits) with one item per nit, starting with the review's `path:line` citation copied exactly: `- <citation> adopted — what you changed` or `- <citation> rejected — why`. The runner files every nit outside the PR's own code as follow-up work unless its citation is marked adopted this way. End the reply with a `## {{CHECKS_HEADING}}` section for the whole PR as it stands after your fix: re-read `git diff origin/main...HEAD` and write `none`, or list the checks to verify, keeping earlier checks that still apply. The runner replaces the PR description's section with it; a reply without it counts as not re-checked and goes to the owner.
